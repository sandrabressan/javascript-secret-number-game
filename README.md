# JavaScript Secret Number Game

A web-based number guessing game developed with **JavaScript, HTML, and CSS** as part of the **Alura Beginner Programming course**.

## How to Play

1. Enter a number to try to guess the secret number.
2. Submit your guess.
3. The game will indicate whether the secret number is higher or lower.
4. Continue guessing until you find the secret number.

* JavaScript
